### 1.2 deep link 可行性结论（读宿主源码）

- **URL 预填：不存在**。chat/conversation 包内 URLSearchParams 全是 Lexical 编辑器内部错误码构造，composer 无 URL 草稿入口；
- **API 路线：可行**。宿主一等包 `dsh-api-session-controller` 暴露 `@Remote('prompt') prompt(request: SessionPromptRequest)`（"Admit one prompt after explicitly resuming its Session"，含 title / prompt / afterSeconds / everySeconds 队列字段）——**网页输入框发消息走的就是这条通道**，设置卡同源同 token 可直达；
- 裁定：FR-1 走 API 路线（session 创建 + prompt 投递的 Remote 类型对齐在实现期完成），不做 Lexical DOM 注入（脆弱），不依赖 URL 形态。

### 1.3 生态位

- awesome-claude-code（55k★）设有 **Session Monitors** 独立类目——会话工具是公认生态位；
- [vir](https://github.com/djolex999/vir)（转写→typed 笔记→MCP 供给）、[Codex Skill](https://github.com/skills-directory/skill-codex)（从 Claude Code 调 Codex 续跑旧会话）说明「蒸馏 + 跨家」正是生态收敛方向；我们在协议与账本语义上仍独占（竞品动态-1008 四点）。

### 1.4 自家摩擦审计（10-08 真机轮实测）

当前接管旅程 **7 步**：面板发现会话 → 复制指令 → 切到新建会话 → 粘贴 → 发送 → 等模型 → 回面板看卡。其中「复制/切会话/粘贴」三步纯属机械搬运，0.5.0 压缩为 **3 步**：面板点按钮 → 自动开会话并投递 → 完成（回面板看卡）。取件旅程同理（`/inbox` 预填投递）。

## 二、产品体验设计（0.5.0 体验目标）

1. **主句式：「看到 → 点一下 → 在跑」**——浏览器的每行会话都是可执行的：`接管`（直发 `/resume-*` 到新会话）、`接管并寄存`（两行式）、取件侧收件箱卡行加「取件」直达。复制按钮保留为降级路径（跨浏览器场景 / API 不可用时）；
2. **列表只留人看的行**：子代理/工作流会话默认收进「子代理（N）」折叠组（对齐 agent-sessions #49 / cc-sessions #3 的用户预期），过滤词可命中折叠内容；
3. **信任体验不删减**：预览的账本语义（HISTORY_REPORTED/停在哪/⚠）是一键化的安全垫——点得越快，越要看得见风险；
4. **失败诚实**：API 投递失败（会话控制器不可达/格式拒绝）回错误横幅并自动退回复制路径，不静默。

## 附录 A · 不做清单决策记录（2026-10-08）

决策方法：每条过同四问——需求真实吗 → 我们做有独到优势还是已有更好人选 → 成本/风险（维护面·安全面·路线分歧）→ 翻案条件。不做 ≠ 永不，是带触发条件的可审计决策；每轮竞品巡检须重扫一遍假设是否仍成立。

| 不做项 | 场景真实性 | 不做的核心理由 | 证据强度 | 翻案条件 |
|--------|-----------|----------------|----------|----------|
| 写别家会话存储 | 真（原生续跑体验天花板，harness-remote/cc-sessions/casr 在做） | 写坏不可逆（**cc-sessions #42/#38 新增案底**；格式无文档随版本漂移）；与只读纪律冲突；蒸馏质量搭模型能力电梯 | **硬**（案底累计三起+路线分歧） | 某家官方开放会话导入 API |
| 成本统计 | 真（ccusage 证明） | 领域冠军已存在，无增量；面板定位是接管运维非仪表盘 | **硬** | 无——除非接管场景真长出用量诉求 |
| 跨设备同步产品化 | 真（agentctxsync 证明） | HANDOFF_HOME 指同步盘一句话兑现 80% 价值（总线即网络层） | **中**（80/20 未经用户实测） | 实测出现同步盘卡冲突损坏 → 做的是「冲突检测告警」（闸），不是同步产品（平台） |
